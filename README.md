# mssk-graph

Интерактивное дерево кодов **МССК 5.0** (Московская строительная система классификаторов, Мосгосэкспертиза). Семь способов отображения: дерево, радиальное дерево, икикл, sunburst, treemap, силовой граф, список.

Живёт на **https://omssng.github.io/mssk-graph/**

Данные — открытые коды классификаторов с [exp.mos.ru](https://exp.mos.ru/project-office-for-implementation-of-bim/mssk/), извлечённые из официальных PDF. `data.js` пересобирается скриптом; вручную не редактируется.
